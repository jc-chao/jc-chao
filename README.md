# Personal projects

#### Invoice extraction with AI (2026)
- OCR → LLM pipeline: extracts text from invoice images using PaddleOCR, then sends it to a local Phi-3 model (via Ollama) to parse structured fields (invoice number, date, vendor, total) into JSON and append them to a CSV.
- Fully local and offline: runs entirely on-device with no cloud APIs; works even on an Intel CPU, though a GPU would be faster.
- [GitHub](https://github.com/jc-chao/extractDetailsFromInvoice)

#### Garmin watch face (2026)
- Displays clean digital time with a cross marker at the top, designed to keep the wearer's focus spiritually grounded throughout the day.
- Shows battery percentage, daily step count and heart rate alongside dual-colour time (hour in white, minute in yellow), with tick marks around the dial.
- Built with the Garmin Connect IQ SDK in Monkey C and tested across 4 devices (FR165, Fenix 7X Pro, Venu 3, Vivoactive 5).
- [GitHub](https://github.com/jc-chao/GarminHourlyVerseWatchFace) | [Live link](https://apps.garmin.com/apps/1c2cac1e-9e58-4997-a445-feca68b99e6c)
